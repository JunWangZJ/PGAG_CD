## PGAG_CD
Patch Group Affinity based Graph for Unsupervised SAR Image Change Detection

## Introduction

Synthetic aperture radar (SAR) image change detection remains challenging due to inherent speckle noise and limited spectral information. To these ends, we propose a patch group affinity based graph (PGAG) for unsupervised SAR image change detection. Specifically, patch groups composed of similar patches extracted from SAR images are designed to enhance the feature representation of objects within the SAR images. Then, these groups are connected to construct a PGAG using edge weights derived from group-based affinities, thereby completing the description of relationships among homogeneous objects. Through modelling graphs on the two SAR images and mapping them onto each other, the change levels can be obtained by accessing the subgraph and structure consistencies between different PGAGs. Finally, binary classification algorithm is applied to obtain the change map. Experiments on three real SAR datasets confirm the superiority of the proposed method, achieving an average accuracy of up to 98%.
